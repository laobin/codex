# plan-review 技能优化记录

## 优化目标

防止 plan-reviewer agent 偏离为主线程自身分析，强制使用当前 Codex 直接进行代码级评审。

## 修改内容

### 1. SKILL.md 修改

**第二步：委托 plan-reviewer agent 执行**
- ✅ 添加【强制】标记，明确 MUST 使用 当前 Codex
- ✅ 委托参数中新增"本次评审要求"字段，显式告知 agent 不得降级
- ✅ 第三步新增【验证】步骤，检查返回的报告是否真正使用了 当前 Codex

### 2. plan-reviewer.md 修改（Agent 执行指令）

**第二步：由当前 Codex 执行 进行评审**
- ✅ 标注【强制要求】- 本步骤 MUST 使用 当前 Codex
- ✅ 明确说明这是与自身分析的根本区别

**注意事项（新增）：【关键】当前 Codex 使用保证**

明确规定：
1. ✅ 当前 Codex **优先级最高**，必须首先尝试
2. ❌ **禁止自动降级** - 不得跳过或自动启用备选方案
3. 🔧 **遇到问题时**：主动告知用户并中断，让用户决定

**备用方案限制**：
- 仅在用户明确授权时才采用
- 必须在报告中标注 ⚠️ 警告

## 效果验证

执行评审后，检查报告中是否包含：
```
- **评审工具**：当前 Codex
- **评审模型**：OpenAI Codex
```

如果显示的模型信息与当前执行模型不一致，说明执行方式异常，需要重新执行。

## 相关文件

- `SKILL.md` - 技能定义（强制 codex 使用）
- `~/.claude/agents/plan-reviewer.md` - Agent 执行指令（禁止自动降级）
